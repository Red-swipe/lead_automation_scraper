# Mentis AI Lead Pipeline

Low volume, manually reviewed outreach for Pakistani education businesses.

## Run

| Command | Behavior |
|---|---|
| `run_mentis.bat` | Safe mode; sends at most one TEST email to `menttis.ai@gmail.com`. |
| `run_mentis_live.bat` | Live path; displays the exact capped batch and requires typing `SEND N`. |
| `python status.py` | Read only relevance, validation, provider, batch, LIVE count, and key status. |

Examples:

```text
run_mentis.bat --skip-scrape
run_mentis.bat --skip-scrape --fake
run_mentis_live.bat --skip-scrape --dry-run
python check_regen.py
python check_llm_failover.py
python check_send_rules.py
```

The six stages are lead finding, relevance filtering, website checks, message
generation, full review, and sending. Google Maps remains optional and skips
when `GOOGLE_PLACES_API_KEY` is missing. Unknown `?` leads are listed and are
never messaged. Google Maps, Instagram, and Facebook scraping are not added.

## Provider failover

The primary provider is selected by `primary_provider` in `config.json` and
defaults to Gemini. `GEMINI_API_KEY` and `GROQ_API_KEY` are loaded from `.env`.
Gemini tries its configured model fallback list. Groq discovers available
models from its API and prefers larger Llama instruct models before smaller
ones. Quota exhaustion or invalid credentials immediately mark that provider
unavailable for the run. Server errors and timeouts use bounded exponential
backoff. If both providers fail, generation saves progress and leaves pending
messages unsent. Messages record the provider and model in `Generated By`.

## Review workbook columns

The working workbook is `leads/mentis_leads_review.xlsx`. Review `Relevant`,
`Priority`, `Review Flag`, `Manual Clear`, `Prompt Version`, `Generated By`,
and `Old Message`. Set `Manual Clear` to `Y` only after personally clearing a
review flag. Current prompt PASS messages are protected from regeneration.
The raw `leads/mentis_leads.xlsx` is only changed by the scraper merge.

## Config and sending

`config.json` contains `daily_cap` (default 3), `min_delay_seconds` (120),
`max_delay_seconds` (300), and `primary_provider` (`gemini` or `groq`). The
daily cap counts only LIVE sends. Raise `daily_cap` cautiously after reviewing
delivery quality; LIVE sends wait a random 2 to 5 minutes with a visible
countdown. Safe mode always sends one TEST email to the owner address.
Live mode requires the exact `SEND N` confirmation and must be launched from
`run_mentis_live.bat`.

## Contact lists and follow up

`leads/do_not_contact.txt` and `leads/already_contacted.txt` take one channel
name or email per line; lines beginning with `#` are ignored. Add opt outs to
`do_not_contact.txt`; add contacts handled outside the pipeline to
`already_contacted.txt`. After sending, check Gmail for bounces and replies.
Add anyone replying STOP to `do_not_contact.txt` promptly. The sender stops on
any SMTP error and sends plain text only.

## Local data

`leads/mentis_leads.xlsx` is the raw scrape; review workbooks, logs, lists, and
backups stay local and gitignored. `.env` contains credentials and is never
printed or committed.
